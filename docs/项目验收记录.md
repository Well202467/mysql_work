# 项目验收记录

## 1. 验收范围

本次验收范围为 `smart_learning` 前后端分离项目，包含：

| 模块 | 验收内容 |
| --- | --- |
| 前端展示页 | 首页、专业列表、专业详情、课程弹窗、职业列表、职业详情 |
| 后台管理页 | 管理员登录、后台首页、9 类数据管理 |
| 后端接口 | 公开查询接口、后台增删改查接口、下拉选项接口 |
| 数据库 | 专业、课程、知识点、职业及关联关系数据 |
| 构建测试 | 前端构建、后端 Maven 测试、接口访问记录 |

## 2. 验收环境

| 项目 | 内容 |
| --- | --- |
| 前端 | Vue 3 + Vite 5 |
| 后端 | Spring Boot 2.7.18 + Java 21 |
| 数据库 | MySQL，数据库名 `smart_learning` |
| 后端端口 | `8086` |
| 前端开发端口 | `5173` |
