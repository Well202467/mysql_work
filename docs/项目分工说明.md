# 项目分工说明

## 1. 分工原则

本项目采用模块化分工方式，不按 Controller、Service、Mapper 等单层结构拆分，而是按业务链路和页面模块拆分。这样可以让每个成员负责一个相对完整的功能闭环，便于开发、联调和答辩说明。

本文档采用角色化分工，不记录个人隐私信息。正式提交时可根据实际小组情况将“成员 A、成员 B、成员 C”替换为真实姓名或学号。

## 6. 协作方式

| 协作事项 | 说明 |
| --- | --- |
| 接口约定 | 后端先根据前端页面字段设计接口，前端再按接口返回字段适配 |
| 数据关系 | 通过 `major_course`、`career_course`、`career_knowledge_point` 等关系表连接业务数据 |
| 返回格式 | 统一使用 `code`、`message`、`data` |
| 错误处理 | 空数据返回空数组，业务校验失败返回明确提示 |
| 文档维护 | 交付文档根据当前源码和验收结果整理 |

## 7. 答辩说明建议

答辩时可以按以下顺序介绍分工：

1. 先介绍整体架构：Vue 前端、Spring Boot 后端、MySQL 数据库。
2. 再介绍后端公开接口如何支撑前台展示。
3. 然后介绍后台 9 类管理模块如何维护数据库数据。
4. 最后说明构建和测试结果：前端构建通过、后端测试通过、接口测试通过。
