# 运行说明

## 1. 环境要求

| 环境 | 要求 |
| --- | --- |
| 操作系统 | Windows、macOS 或 Linux 均可 |
| JDK | Java 21，需与 `backend/pom.xml` 配置一致 |
| Maven | 可执行 `mvn` 命令 |
| Node.js | 可运行 Vite 5 项目 |
| npm | 可执行 `npm install`、`npm.cmd run build` |
| MySQL | 建议 MySQL 8.x |

## 2. 端口说明

| 服务 | 默认端口 | 配置位置 |
| --- | --- | --- |
| 后端 Spring Boot | `8086` | `backend/src/main/resources/application.yml` |
| 前端 Vite 开发服务 | `5173` | Vite 默认端口 |
| 前端代理 | `/api -> http://localhost:8086` | `fronted/vite.config.js` |

前端接口请求在 `fronted/src/api/request.js` 中配置为 `http://localhost:8086`，因此本地联调时后端应先在 `8086` 端口启动。

## 3. 数据库准备

1. 在 MySQL 中准备数据库：

```sql
CREATE DATABASE smart_learning DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

2. 根据项目已有数据库数据导入 `major`、`course`、`major_course`、`knowledge_point`、`career`、`career_profile`、`career_ability`、`career_course`、`career_knowledge_point` 等表。

3. 修改 `backend/src/main/resources/application.yml` 中本机数据库连接信息：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/smart_learning?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false
    username: your_username
    password: your_password
```

说明：交付文档不记录真实数据库密码，请以本机 MySQL 配置为准。

## 4. 启动后端

进入后端目录：

```bash
cd backend
```

安装依赖并启动：

```bash
mvn spring-boot:run
```

启动成功后，后端基础地址为：

```text
http://localhost:8086
```

可访问接口文档页面：

```text
http://localhost:8086/swagger-ui/index.html
```

## 5. 启动前端

进入前端目录：

```bash
cd fronted
```

安装依赖：

```bash
npm install
```

启动开发服务：

```bash
npm run dev
```

浏览器访问：

```text
http://localhost:5173
```

## 6. 前端构建

在 `fronted` 目录执行：

```bash
npm.cmd run build
```

构建成功后会生成 `fronted/dist` 目录。该目录是构建产物，不属于源码重点分析范围。

## 7. 后端测试

在 `backend` 目录执行：

```bash
mvn test
```

项目最终验收中，后端 `mvn test` 已通过。当前后端主要通过接口访问和 Maven 测试阶段完成验收检查。

## 8. 常用访问路径

| 页面 | 地址 |
| --- | --- |
| 首页 | `http://localhost:5173/` |
| 专业列表 | `http://localhost:5173/majors` |
| 职业列表 | `http://localhost:5173/careers` |
| 管理员登录 | `http://localhost:5173/admin/login` |
| 后台首页 | `http://localhost:5173/admin/dashboard` |

## 9. 常见问题

| 问题 | 排查方式 |
| --- | --- |
| 前端页面请求失败 | 确认后端是否已在 `8086` 端口启动 |
| 后端启动失败 | 检查 JDK 版本、MySQL 是否启动、数据库连接配置是否正确 |
| 数据为空 | 检查 `smart_learning` 数据库是否已导入业务表和测试数据 |
| 后台接口返回未登录 | 确认已通过 `/admin/login` 登录，前端会自动携带 `Authorization` 请求头 |
| 构建失败 | 先执行 `npm install`，再执行 `npm.cmd run build` |
