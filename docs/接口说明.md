# 接口说明

## 1. 接口基础信息

| 项目 | 内容 |
| --- | --- |
| 后端基础地址 | `http://localhost:8086` |
| 公开接口前缀 | `/api/majors`、`/api/courses`、`/api/careers` |
| 后台接口前缀 | `/api/admin` |
| 接口文档 | `/swagger-ui/index.html` |
| 返回格式 | `code`、`message`、`data` |

公开展示接口主要服务前台页面，后台管理接口主要服务管理员页面。后台除登录接口外，其他 `/api/admin/**` 请求需要携带登录后获得的 `Authorization` 请求头。

## 2. 统一返回格式

公开查询接口使用 `ApiResponse`：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

后台管理接口使用 `Result`：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

后台业务校验失败时，通常返回：

```json
{
  "code": 400,
  "message": "错误原因",
  "data": null
}
```

未登录或 token 无效时，返回 `401` 相关结果。

## 3. 公开展示接口

### 3.1 专业接口

| 方法 | 路径 | 说明 | 主要返回字段 |
| --- | --- | --- | --- |
| GET | `/api/majors` | 查询专业列表 | `id`、`name`、`intro`、`createdAt`、`updatedAt` |
| GET | `/api/majors/{id}` | 根据专业 ID 查询专业详情 | `id`、`name`、`intro` |
| GET | `/api/majors/{id}/courses` | 查询某个专业的课程 | `id`、`name`、`description`、`type`、`credits` |

对应前端页面：

| 页面 | 调用接口 |
| --- | --- |
| `/majors` | `GET /api/majors` |
| `/major/:id` | `GET /api/majors/{id}`、`GET /api/majors/{id}/courses` |

### 3.2 课程接口

| 方法 | 路径 | 说明 | 主要返回字段 |
| --- | --- | --- | --- |
| GET | `/api/courses/{id}/knowledge-points` | 根据课程 ID 查询知识点列表 | `id`、`courseId`、`name`、`description`、`difficulty`、`ability`、`source` |
| GET | `/api/courses/{courseId}/careers` | 根据课程 ID 反查关联职业 | `careerId`、`careerName`、`category`、`courseRole`、`relatedAbility`、`relatedPoints`、`importance`、`isCore`、`learningStage` |

### 3.3 职业接口

| 方法 | 路径 | 说明 | 主要返回字段 |
| --- | --- | --- | --- |
| GET | `/api/careers` | 查询职业列表 | `id`、`name`、`category`、`sortOrder`、`createdAt`、`updatedAt` |
| GET | `/api/careers/{id}` | 根据职业 ID 查询职业详情 | `id`、`name`、`category`、`sortOrder`、`createdAt`、`updatedAt` |
| GET | `/api/careers/{id}/courses` | 查询职业关联课程 | `courseId`、`courseName`、`courseDescription`、`courseRole`、`relatedAbility`、`relatedPoints`、`importance`、`isCore`、`learningStage` |
| GET | `/api/careers/{id}/abilities` | 查询职业能力 | `id`、`careerId`、`name`、`description`、`abilityType`、`importance`、`learningAdvice` |
| GET | `/api/careers/{id}/knowledge-points` | 查询职业关联知识点 | `id`、`careerId`、`courseId`、`courseName`、`knowledgePointId`、`knowledgePointName`、`knowledgePointDescription`、`useScene`、`importance`、`learningAdvice`、`source` |

对应前端页面：

| 页面 | 调用接口 |
| --- | --- |
| `/careers` | `GET /api/careers` |
| `/careers/:id` | `GET /api/careers/{id}`、`GET /api/careers/{id}/courses`、`GET /api/careers/{id}/abilities`、`GET /api/careers/{id}/knowledge-points` |

## 4. 后台登录接口

| 方法 | 路径 | 说明 | 请求字段 | 返回字段 |
| --- | --- | --- | --- | --- |
| POST | `/api/admin/login` | 管理员登录 | `username`、`password` | `token` |

说明：本文档不记录实际登录账号和密码。前端登录成功后，会将后端返回的 token 保存到 `localStorage.adminToken`，后续后台接口由 Axios 拦截器自动放入 `Authorization` 请求头。

## 5. 后台管理接口

### 5.1 专业管理

| 方法 | 路径 | 说明 | 请求字段 |
| --- | --- | --- | --- |
| GET | `/api/admin/majors` | 查询专业列表 | 无 |
| POST | `/api/admin/majors` | 新增专业 | `id`、`name`、`intro` |
| PUT | `/api/admin/majors/{id}` | 修改专业 | `id`、`name`、`intro` |
| DELETE | `/api/admin/majors/{id}` | 删除专业 | 无 |

主要校验：专业 ID 和专业名称不能为空；不允许修改主键 ID；已关联专业课程时不能直接删除。

### 5.2 课程管理

| 方法 | 路径 | 说明 | 请求字段 |
| --- | --- | --- | --- |
| GET | `/api/admin/courses` | 查询课程列表 | 无 |
| POST | `/api/admin/courses` | 新增课程 | `id`、`name`、`description` |
| PUT | `/api/admin/courses/{id}` | 修改课程 | `id`、`name`、`description` |
| DELETE | `/api/admin/courses/{id}` | 删除课程 | 无 |

主要校验：课程 ID 和课程名称不能为空；课程名称不能重复；课程被专业、知识点或职业关系引用时不能直接删除。

### 5.3 专业课程关系管理

| 方法 | 路径 | 说明 | 请求字段 |
| --- | --- | --- | --- |
| GET | `/api/admin/major-courses` | 查询专业课程关系列表 | 无 |
| POST | `/api/admin/major-courses` | 新增专业课程关系 | `majorId`、`courseId`、`type`、`credits` |
| PUT | `/api/admin/major-courses/{id}` | 修改专业课程关系 | `id`、`majorId`、`courseId`、`type`、`credits` |
| DELETE | `/api/admin/major-courses/{id}` | 删除专业课程关系 | 无 |

主要校验：专业和课程必须存在；同一专业和课程的关联不能重复。

### 5.4 知识点管理

| 方法 | 路径 | 说明 | 请求字段 |
| --- | --- | --- | --- |
| GET | `/api/admin/knowledge-points` | 查询知识点列表 | 无 |
| POST | `/api/admin/knowledge-points` | 新增知识点 | `courseId`、`name`、`description`、`difficulty`、`ability`、`source` |
| PUT | `/api/admin/knowledge-points/{id}` | 修改知识点 | `id`、`courseId`、`name`、`description`、`difficulty`、`ability`、`source` |
| DELETE | `/api/admin/knowledge-points/{id}` | 删除知识点 | 无 |

主要校验：课程必须存在；知识点名称不能为空；被职业知识点关系引用时不能直接删除。

### 5.5 职业管理

| 方法 | 路径 | 说明 | 请求字段 |
| --- | --- | --- | --- |
| GET | `/api/admin/careers` | 查询职业列表 | 无 |
| POST | `/api/admin/careers` | 新增职业 | `id`、`name`、`category`、`sortOrder` |
| PUT | `/api/admin/careers/{id}` | 修改职业 | `id`、`name`、`category`、`sortOrder` |
| DELETE | `/api/admin/careers/{id}` | 删除职业 | 无 |

主要校验：职业 ID 和职业名称不能为空；职业名称不能重复；被职业画像、职业能力、职业课程或职业知识点引用时不能直接删除。

### 5.6 职业画像管理

| 方法 | 路径 | 说明 | 请求字段 |
| --- | --- | --- | --- |
| GET | `/api/admin/career-profiles` | 查询职业画像列表 | 无 |
| POST | `/api/admin/career-profiles` | 新增职业画像 | `careerId`、`intro`、`workContent`、`requirement`、`commonTech`、`suitableMajor`、`developmentPath`、`source` |
| PUT | `/api/admin/career-profiles/{id}` | 修改职业画像 | `id` 及新增字段 |
| DELETE | `/api/admin/career-profiles/{id}` | 删除职业画像 | 无 |

主要校验：职业必须存在；一个职业只允许一条职业画像记录；`intro`、`workContent`、`requirement` 不能为空。

### 5.7 职业能力管理

| 方法 | 路径 | 说明 | 请求字段 |
| --- | --- | --- | --- |
| GET | `/api/admin/career-abilities` | 查询职业能力列表 | 无 |
| POST | `/api/admin/career-abilities` | 新增职业能力 | `careerId`、`name`、`description`、`abilityType`、`importance`、`learningAdvice` |
| PUT | `/api/admin/career-abilities/{id}` | 修改职业能力 | `id` 及新增字段 |
| DELETE | `/api/admin/career-abilities/{id}` | 删除职业能力 | 无 |

主要校验：职业必须存在；职业能力名称不能为空。

### 5.8 职业课程关系管理

| 方法 | 路径 | 说明 | 请求字段 |
| --- | --- | --- | --- |
| GET | `/api/admin/career-courses` | 查询职业课程关系列表 | 无 |
| POST | `/api/admin/career-courses` | 新增职业课程关系 | `careerId`、`courseId`、`courseRole`、`relatedAbility`、`relatedPoints`、`importance`、`isCore`、`learningStage` |
| PUT | `/api/admin/career-courses/{id}` | 修改职业课程关系 | `id` 及新增字段 |
| DELETE | `/api/admin/career-courses/{id}` | 删除职业课程关系 | 无 |

主要校验：职业和课程必须存在；同一职业和课程的关联不能重复；`isCore` 为空时默认按非核心课程处理。

### 5.9 职业知识点关系管理

| 方法 | 路径 | 说明 | 请求字段 |
| --- | --- | --- | --- |
| GET | `/api/admin/career-knowledge-points` | 查询职业知识点关系列表 | 无 |
| POST | `/api/admin/career-knowledge-points` | 新增职业知识点关系 | `careerId`、`courseId`、`knowledgePointId`、`useScene`、`importance`、`learningAdvice`、`source` |
| PUT | `/api/admin/career-knowledge-points/{id}` | 修改职业知识点关系 | `id` 及新增字段 |
| DELETE | `/api/admin/career-knowledge-points/{id}` | 删除职业知识点关系 | 无 |

主要校验：职业、课程、知识点必须存在；知识点必须属于当前课程；同一职业和知识点的关联不能重复。

## 6. 后台下拉选项接口

| 方法 | 路径 | 说明 | 参数 |
| --- | --- | --- | --- |
| GET | `/api/admin/options/majors` | 查询专业下拉选项 | 无 |
| GET | `/api/admin/options/courses` | 查询课程下拉选项 | 无 |
| GET | `/api/admin/options/careers` | 查询职业下拉选项 | 无 |
| GET | `/api/admin/options/knowledge-points` | 查询知识点下拉选项 | 可选 `courseId` |

返回字段统一为：

| 字段 | 说明 |
| --- | --- |
| `value` | 选项值 |
| `label` | 选项显示文本 |
