# 功能说明

## 1. 功能总览

`smart_learning` 项目围绕软件学院学生的学习路径和职业方向展开。当前实现的核心功能是将专业、课程、知识点、职业、职业能力和职业课程关系串联起来，让学生能够从专业出发理解课程价值，也能从职业方向反向查看需要学习的课程和知识点。

当前代码未实现复杂推荐算法，也没有独立的资源库管理接口。项目中的“学习推荐”主要体现在专业、课程、知识点和职业之间的结构化关联展示。

## 2. 前台展示功能

### 2.1 首页

| 项目 | 说明 |
| --- | --- |
| 路由 | `/` |
| 文件 | `fronted/src/views/HomeView.vue` |
| 功能 | 展示网站定位、专业/课程/能力/岗位学习关系和入口 |
| 数据来源 | 页面内静态文案 |

首页用于引导用户理解平台目标，并进入专业列表或职业方向页面。

### 2.2 专业列表

| 项目 | 说明 |
| --- | --- |
| 路由 | `/majors` |
| 文件 | `fronted/src/views/MajorCatalogView.vue` |
| 接口 | `GET /api/majors` |
| 功能 | 展示专业卡片，点击进入专业详情 |

页面会从后端读取专业数据，并对 `id`、`name`、`intro` 等字段做前端兜底处理。

### 2.3 专业详情

| 项目 | 说明 |
| --- | --- |
| 路由 | `/major/:id` |
| 文件 | `fronted/src/views/MajorView.vue` |
| 接口 | `GET /api/majors/{id}`、`GET /api/majors/{id}/courses` |
| 功能 | 展示专业简介、课程结构、能力方向、职业方向和课程列表 |

专业详情页会根据专业课程继续加载：

| 数据 | 接口 |
| --- | --- |
| 课程知识点 | `GET /api/courses/{id}/knowledge-points` |
| 课程关联职业 | `GET /api/courses/{courseId}/careers` |

页面支持课程搜索和按课程类型筛选。

### 2.4 课程详情弹窗

| 项目 | 说明 |
| --- | --- |
| 组件 | `fronted/src/components/CourseModal.vue` |
| 打开位置 | 专业详情页课程列表 |
| 功能 | 展示课程说明、课程知识点、关联职业和课程作用 |

用户点击课程后，前端会并行请求课程知识点和课程关联职业，再将结果传入弹窗组件展示。

### 2.5 职业列表

| 项目 | 说明 |
| --- | --- |
| 路由 | `/careers` |
| 文件 | `fronted/src/views/CareerCatalogView.vue` |
| 接口 | `GET /api/careers` |
| 功能 | 展示职业方向卡片，点击进入职业详情 |

页面展示职业名称、职业类别和职业编号。

### 2.6 职业详情

| 项目 | 说明 |
| --- | --- |
| 路由 | `/careers/:id` |
| 文件 | `fronted/src/views/CareerDetailView.vue` |
| 接口 | `GET /api/careers/{id}`、`GET /api/careers/{id}/courses`、`GET /api/careers/{id}/abilities`、`GET /api/careers/{id}/knowledge-points` |
| 功能 | 展示职业基础信息、相关课程、核心能力、相关知识点 |

职业详情页将多个接口的数据组合展示，便于从职业方向反向理解课程和知识点。

## 3. 后台管理功能

### 3.1 管理员登录

| 项目 | 说明 |
| --- | --- |
| 路由 | `/admin/login` |
| 文件 | `fronted/src/views/admin/AdminLogin.vue` |
| 接口 | `POST /api/admin/login` |
| 功能 | 管理员登录，成功后保存 token 并进入后台 |

登录成功后，前端请求拦截器会把 token 放入 `Authorization` 请求头。本文档不记录实际账号和密码。

### 3.2 后台首页

| 项目 | 说明 |
| --- | --- |
| 路由 | `/admin/dashboard` |
| 文件 | `fronted/src/views/admin/AdminDashboard.vue` |
| 功能 | 展示 9 类管理入口 |

后台布局文件 `AdminLayout.vue` 提供左侧导航、顶部栏和退出登录功能。

### 3.3 9 类数据管理

| 模块 | 路由 | 功能 |
| --- | --- | --- |
| 专业管理 | `/admin/majors` | 维护专业 ID、名称、简介 |
| 课程管理 | `/admin/courses` | 维护课程 ID、名称、说明 |
| 专业课程关系管理 | `/admin/major-courses` | 维护专业和课程关系、课程类型、学分 |
| 知识点管理 | `/admin/knowledge-points` | 维护课程知识点、难度、能力和来源 |
| 职业管理 | `/admin/careers` | 维护职业 ID、名称、类别和排序 |
| 职业画像管理 | `/admin/career-profiles` | 维护职业介绍、工作内容、能力要求、技术和发展路径 |
| 职业能力管理 | `/admin/career-abilities` | 维护职业能力、能力类型、重要程度和学习建议 |
| 职业课程关系 | `/admin/career-courses` | 维护职业与课程关系、核心课程、学习阶段 |
| 职业知识点关系 | `/admin/career-knowledge-points` | 维护职业与知识点关系、应用场景和学习建议 |

这些页面均支持列表查看、新增、编辑和删除。删除时后端会检查引用关系，避免误删仍被其他表使用的数据。

## 4. 后端功能

| 模块 | 说明 |
| --- | --- |
| 专业模块 | 查询专业列表、专业详情、专业课程 |
| 课程模块 | 查询课程知识点、课程关联职业 |
| 职业模块 | 查询职业列表、职业详情、职业课程、职业能力、职业知识点 |
| 后台管理模块 | 提供 9 类数据的增删改查 |
| 登录拦截 | 除 `/api/admin/login` 外，后台接口需要 token |
| 跨域配置 | 允许前端开发地址访问后端 `/api/**` |
| OpenAPI | 提供 Swagger 接口文档页面 |

## 5. 数据流说明

### 5.1 专业到课程

```text
专业 major
  -> 专业课程关系 major_course
  -> 课程 course
  -> 知识点 knowledge_point
```

### 5.2 职业到课程和知识点

```text
职业 career
  -> 职业课程关系 career_course
  -> 课程 course

职业 career
  -> 职业能力 career_ability

职业 career
  -> 职业知识点关系 career_knowledge_point
  -> 知识点 knowledge_point
```
