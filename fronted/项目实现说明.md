# 软件学院专业课程与能力导航平台 — 项目实现说明

本文档说明本纯前端 Vue3 项目的**建设过程**与**目录结构**，便于交接、答辩或二次开发时快速建立全局认识。

---

## 一、项目概述

本项目是一个**教学展示向**的「软件学院专业课程与能力导航」单页应用：用户在首页了解学院与平台概况，按专业进入课程目录，通过搜索与类型筛选缩小范围，点击课程查看与**能力、岗位**相关的说明。数据全部来自本地 **`src/data/majors.js`**，**不接后端、不接数据库**。

---

## 二、技术栈

| 类别 | 选型 |
|------|------|
| 框架 | Vue 3（组合式 API，`<script setup>`） |
| 语言 | JavaScript（不使用 TypeScript） |
| 构建 | Vite 5 |
| 路由 | Vue Router 4（`createWebHistory`） |
| 样式 | 各组件内 Scoped CSS，无第三方 UI 库 |

## 三、实现过程（按迭代顺序）

### 1. 方案与数据准备

- 确定信息架构：**首页**（学院介绍 + 专业入口）→ **专业页**（简介 + 课程列表）→ **课程详情弹窗**（能力、岗位、岗位说明）。
- 约定路由：`/` 首页，`/major/:id` 专业页，`id` 与数据中的专业 `id` 一致（如 `software-engineering`）。
- 在 `src/data/majors.js` 中维护 **`majors`** 数组：每个专业含 `id`、`name`、`intro`、`courses`；每门课含 `id`、`name`、`type`（必修/选修）、`description`、`skills`、`jobs`、`jobExplanation`。
- 后续根据学院提供的 **Word 培养方案**（`资料` 目录）将三门专业的**必修/选修课程名单**补全，并保持 `getMajorById`、`getAllMajors` 等导出不变，以免影响页面。

### 2. 可运行的基础脚手架

- 初始化 **Vite + Vue** 工程：`package.json`、`vite.config.js`、`index.html`。
- `src/main.js` 创建应用并挂载；`vite.config.js` 配置 `@` → `src` 别名（便于后续扩展）。
- `src/App.vue` 先作为最小容器，验证 `npm install` / `npm run dev` 可正常启动。

### 3. 路由与页面骨架

- 新增 `src/router/index.js`：注册 `HomeView`、`MajorView`；`main.js` 中 `app.use(router)`。
- `App.vue` 调整为**顶栏标题 + `<RouterView />`**，具体页面内容下沉到 `views`。
- `HomeView`：平台标题、学院简介、三个专业入口卡片（`RouterLink` 跳转专业页）。
- `MajorView`：根据路由参数 `id` 调用 `getMajorById` 拉取专业数据；展示简介与课程列表（名称、类型、简介摘要）；无效 `id` 时给出提示与返回首页链接。

### 4. 课程详情弹窗

- 新增 `src/components/CourseModal.vue`：通过 **`props.course`** 接收当前课程；**`emit('close')`** 通知父组件关闭。
- 展示：课程名、类型、简介、`skills` / `jobs` 标签化展示、`jobExplanation`；对空字段做「暂无…」类兜底。
- 关闭方式：右上角按钮、点击遮罩、`Esc` 键；使用 **`Teleport`** 挂到 `body`，避免层级被父布局裁剪。
- `MajorView` 内维护 **`showModal`**、**`selectedCourse`**，列表项可点击打开弹窗，关闭时清空状态；切换专业路由时同步关闭弹窗并清空选中课程。

### 5. 专业页：搜索与类型筛选

- 在 `MajorView` 课程列表上方增加**工具区**：课程名称模糊搜索（兼容 `name` / `title`）、类型筛选（全部 / 必修 / 选修，兼容 `type` / `courseType` / `kind`）。
- 使用 **`computed`** 得到 `filteredCourses`，搜索与筛选可叠加；展示「共 N 门课程」为当前结果数量；无匹配时显示空状态文案。
- 切换专业路由时：清空搜索词、筛选回到「全部」，并关闭弹窗（与第 4 步状态管理一致）。
- **未改** `CourseModal.vue` 的对外接口，保证弹窗逻辑稳定。

### 6. 首页：平台概览统计

- 在 `HomeView` 增加 **「平台概览」** 区块：基于 `getAllMajors()` 动态统计**专业数量**、**课程总数**、**岗位方向去重数**（遍历课程 `jobs` / `positions`，兼容字符串与对象数组）。
- 优化首页层次：标题 → 学院简介卡片 → 概览统计卡 → 专业入口卡（含「进入课程目录」提示）。
- 路由与专业页、弹窗逻辑保持不变。

### 7. 数据补全（课程名单）

- 依据 `资料` 中《软件学院各专业必修课》等文档，将三门专业课程按 **必修 / 选修** 完整录入 `majors.js`；文档未展开的细节由**合理、通用的教学描述**补充，以满足弹窗与列表展示需求。
- 使用内部工厂函数 `C(...)` 压缩重复字段书写，**不改变** `export const majors` 与 `getMajorById` / `getAllMajors` 的对外接口。

## 四、目录与关键文件说明

以下为**仓库根目录**下与开发直接相关的结构（`node_modules`、`dist` 等为构建产物或依赖，一般不纳入业务说明）。

```
网页/
├── index.html              # Vite HTML 入口，挂载 #app，引入 /src/main.js
├── package.json            # 项目依赖与 npm 脚本（dev / build / preview）
├── package-lock.json       # 依赖锁定文件
├── vite.config.js          # Vite 配置：Vue 插件、路径别名 @ → src
├── 项目实现说明.md         # 本说明文档
├── public/                 # 不参与打包的静态资源（如图标），可按需使用
├── 资料/                   # 学院 Word 等原始材料（课程名单来源，不参与构建）
└── src/
    ├── main.js             # 应用入口：createApp、安装 router、mount('#app')
    ├── App.vue             # 根布局：站点顶栏标题 + <RouterView />
    ├── router/
    │   └── index.js        # 路由表：/ → HomeView，/major/:id → MajorView
    ├── views/
    │   ├── HomeView.vue    # 首页：标题、学院简介、平台概览统计、专业入口卡片
    │   └── MajorView.vue   # 专业页：简介、搜索/筛选、课程列表、CourseModal 状态
    ├── components/
    │   └── CourseModal.vue # 课程详情弹窗（Teleport + 关闭交互 + 字段兼容）
    └── data/
        └── majors.js       # 全站数据源：专业与课程、导出查询函数
```

### 各目录职责简述

| 路径 | 作用 |
|------|------|
| **`/` 根目录** | 工程配置与入口 HTML；`npm` 脚本与 Vite 配置所在。 |
| **`public/`** | 静态资源目录，构建时原样拷贝；适合放 `favicon` 等。 |
| **`资料/`** | 教学文档归档，供人工维护 `majors.js` 时对照，**不参与** Vite 打包。 |
| **`src/`** | 全部业务源码（Vue 组件、路由、本地数据）。 |
| **`src/router/`** | 路由定义与历史模式配置，控制页面级 URL 与组件映射。 |
| **`src/views/`** | **页面级**组件，由路由直接渲染；负责拼装数据与调用子组件。 |
| **`src/components/`** | **可复用** UI 片段（如弹窗）；与路由无直接绑定，由页面引用。 |
| **`src/data/`** | 本地 Mock 数据与导出函数；后续若接 API，可逐步替换为请求层，页面 import 路径尽量稳定。 |

### 关键文件一览

| 文件 | 用处 |
|------|------|
| **`index.html`** | 浏览器入口页面，提供 `#app` 根节点与模块脚本入口。 |
| **`vite.config.js`** | 配置 Vue 单文件组件支持、`@` 别名等构建行为。 |
| **`package.json`** | 声明 `vue`、`vue-router`、`vite` 等依赖及开发命令。 |
| **`src/main.js`** | 组装根实例并注册插件（Router），挂载应用。 |
| **`src/App.vue`** | 全站壳子：统一顶栏与主内容区，主内容即路由视图。 |
| **`src/router/index.js`** | 声明路径与组件对应关系，是单页应用「多页体验」的核心。 |
| **`src/views/HomeView.vue`** | 门户页：介绍、统计数据、进入各专业的入口。 |
| **`src/views/MajorView.vue`** | 专业课程中心：过滤课程、打开详情弹窗、返回首页。 |
| **`src/components/CourseModal.vue`** | 课程详情呈现与无障碍相关属性；与业务数据字段解耦（带兼容分支）。 |
| **`src/data/majors.js`** | 唯一结构化数据源；**专业数、课程列表、岗位统计**等均派生自此文件。 |

### 可选扩展（当前仓库未强制使用）

- **`src/assets/`**：可放置图片、全局 `css` 等静态资源；当前项目将样式写在各 `.vue` 内，故未单独建该目录也可运行。若后续统一主题，可将公共变量提取到 `src/assets/styles/`。

## 六、小结

项目按「**脚手架 → 路由与页面 → 弹窗 → 专业页检索 → 首页概览 → 数据补全**」逐步迭代，始终保持 **Vue3 + JS + Vite** 技术栈与 **纯前端 Mock** 边界；业务复杂度主要集中在 **`MajorView` 的交互状态**与 **`majors.js` 的数据维护**，其余目录职责清晰，便于后续接入真实接口或拆分子模块。
